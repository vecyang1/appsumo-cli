# v0.5.1 — fewer false recommendations, sturdier Notion sync

Released 2026-10-07. Not yet tagged.

A round of duplicate-detection and operational fixes for the weekly buy advisor.

## Fixed

- **Duplicate recommendations leak** — resolved false-positive recommendations
  (ElkQR, Switchy, BeHuman.Online, Measuremate, InstaCharts, TeliportMe, AR/3D
  viewers) by expanding `COMPETITOR_TO_OWNED_ASSET` with Bitly, Rebrandly, and
  Linktree (mapped to owned link tools), Zoom, Hopin, and ON24 (mapped to
  GoBrunch), Flourish (mapped to Logic Sheet plus local visualization), and
  Powtoon (mapped to Remotion and Manim).
- **Broader saturated-subcategory coverage** — added Virtual Events, Website
  Analytics, Data & Reporting, Paid Ads & Retargeting, Photo Editing, and Design
  Tools to `SATURATED_SUBCATEGORIES`, so candidate deals pass deduplication and
  emit a clean zero-recommendation verdict.
- **CLI global availability** — created a `~/.local/bin/cadence_ctl` symlink so
  `cadence_ctl validate`, `doctor`, and `test-sidecar` run from any working
  directory.
- **Console output formatting** — a `status == "skipped"` run no longer prints
  `None 款 | None 款`.
- **Notion block duplication and chunked-encoding crash** — `cleanup_previous_notion_runs`
  now uses `curl` instead of `urllib.request`, avoiding Python 3.14
  `http.client.IncompleteRead` errors and maintaining a single authoritative
  verdict block.
- **Expanded unit tests** — added 6 new tests (19/19 passing) covering link
  shorteners, QR tools, virtual events, chart embedders, GA4/GTM wrappers, and
  out-of-domain checks.
