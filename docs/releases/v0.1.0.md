# v0.1.0 — read-only AppSumo buyer-account CLI

Released 2026-06-16. Never tagged; `v0.2.0` is the first tagged release.

The initial cut of a read-only AppSumo buyer-account CLI: inspect your purchases,
export them safely, and query a local snapshot — without any command that
refunds, transfers, activates, changes plans, checks out, or mutates account
data.

## Added

- **Account surface:** `appsumo auth` status, `appsumo products` list/search/export,
  `appsumo sync`, local search, and read-only `appsumo sql`.
- **Documented endpoint discovery and safety contract**, including the strict
  default redaction requirement for license and code export fields.
- **CLI Printing Press baseline** generated and shipchecked from the read-only
  OpenAPI contract, with the generated output kept under an ignored directory.
- **Community-ready packaging:** public module path, CI, license, and security
  notes.

## Safety

- **CSV license/code redaction is non-optional.** The removed `--redact-codes`
  opt-out is rejected rather than accepted and ignored.
- **Cookie forwarding is hardened** so a `--base-url` override cannot receive a
  real AppSumo cookie outside AppSumo or loopback test hosts.
- **Oversized AppSumo responses fail explicitly** instead of silently truncating
  an export.
- **User SQL runs under SQLite `query_only` mode**, so a read-only session cannot
  write to the local database.

## Verification

- Live read-only smoke against a logged-in browser session, without printing
  cookies, including a successful product sync.
- Go 1.26.3+ required in CI and contributor checks so standard-library
  vulnerability scans stay clean. (The floor was later raised to 1.26.6 in
  0.2.0.)
