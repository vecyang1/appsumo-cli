# v0.5.3 — URL, query, and schema edge cases

Released 2026-10-08. Not yet tagged.

Fixes for the edge cases where a filter, a URL, or an unusual deal schema could
produce a confidently wrong answer.

## Fixed

- **Client-side filter pagination completeness (`ScannedDeals`)** — added
  `ScannedDeals` to the Go `DealsResult` and its `Complete()` logic, preventing
  false-positive truncation alerts when a filtered scan matches fewer deals than
  the declared total.
- **URL query/fragment stripping (`CleanProductSlug`)** — hardened in both Go and
  Python to strip fragment identifiers (`#...`) and query strings (`?...`),
  correctly parsing schemaless URLs and bare path inputs.
- **Unbounded store queries** — `IdealDealsQuery` now treats `limit <= 0` as "all
  matching deals" instead of clamping to 20, and `db.GetDeal(ctx, slug)` supports
  single-deal retrieval.
- **Python 3.14 chunked-encoding resilience** — switched `fetch_deal_by_slug`
  from `urllib.request` to a `curl` subprocess, preventing
  `http.client.IncompleteRead` crashes on AppSumo chunked HTTP responses.
- **Deal schema normalization and title preservation** — added
  `_normalize_scraped_deal` to map local `data/<slug>/deal.json` and SQLite rows
  into a unified `Deal` format (avoiding `name = None` and `$0.00` price
  false-positives), preserved hyphenated brand names when splitting asset titles,
  and added short-token protection in `is_owned`.
- **Graceful unresolved-deal handling** — `audit_deal_steps` handles unresolved
  deals by checking existing portfolio ownership first, then triggering a catalog
  metadata existence gate if unknown, preventing a false Rule 0 trigger.
- **Expanded test suite** — 31/31 Python tests and all Go tests passing, covering
  schemaless URL parsing, hyphenated name preservation, token collision
  protection, and unresolved-deal audits.
