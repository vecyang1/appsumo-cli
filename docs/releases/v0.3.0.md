# v0.3.0 — catalog search, ideal-deal discovery, and Notion sync

Released 2026-09-10. Not yet tagged.

The public deal catalog grew from a raw listing into a searchable, filterable
discovery surface, with a daily monitor cadence and native Notion sync.

## Added

- **`appsumo deals search <query>`** — keyword search over live public AppSumo
  deals or a synced local SQLite snapshot (`--local`).
- **`appsumo deals ideal`** — detect and filter ideal deals (rating ≥ 4.5 and at
  least 10 reviews by default), tunable with `--min-rating`, `--min-reviews`,
  `--query`, `--category`, `--max-price`, and `--local`.
- **Rich ideal-deal output** — `--chinese` (`-c`) and `--format table|card|markdown`
  render Chinese product recommendation cards with product links, pricing,
  discount calculations, value proposition, and competitor comparisons.
- **`appsumo deals sync-notion`** — sync curated ideal deals straight to Notion
  with customizable thresholds and no external dependencies.
- **New filters on `appsumo deals list`** — `--query`, `--min-rating`,
  `--min-reviews`, `--max-price`, and `--category`.
- **`--deals` on `appsumo search <query>`** — query synced catalog deals from
  local SQLite alongside owned products.
- **Richer deal metadata** — persist `card_description`, `value_prop`, `best_for`,
  `alternative_to`, `integrations`, and `subcategory`.
- **Store query APIs** — `SearchDeals`, `IdealDeals`, and `IdealDealsQuery`, with
  automatic column migrations on SQLite.
- **Daily monitor cadence** — `com.vec.appsumo-deal-monitor` LaunchAgent and
  `scripts/run_appsumo_monitor.sh` for persistent catalog tracking and Notion
  synchronization.

## Fixed

- **No more premature truncation in `FetchAllDealsQuery`** — walking candidate
  deals across pages and sorting deterministically by
  `(average_rating DESC, review_count DESC, price ASC)` prevents dropping
  higher-rated products that appear on later pages.
- **Pagination cycle detection decoupled from client-side filters** — the
  `newUnseen == 0` guard no longer produces false-positive early halts while
  still preventing infinite pagination loops.
- **Filters pushed down to SQLite** — `--query`, `--category`, and `--max-price`
  are applied in `IdealDealsQuery`, so in-memory filtering of a pre-limited slice
  no longer drops valid matching deals.
- **`scripts/sync_notion_recommendations.py` made runnable** — resolves the
  binary path dynamically, accepts CLI arguments (`--page-id`, `--token`,
  `--min-rating`, `--min-reviews`, `--limit`, `--local`), and runs reliably
  outside the repository working directory.
- **Accurate local provenance** — CLI output headers report the local database
  source instead of "unknown live deals in 0 requests".
- **Install smoke coverage** — `deals search`, `deals ideal`, and
  `deals sync-notion` are now graded by `scripts/install_smoke.sh`.

## API notes

Verified live: the AppSumo Elasticsearch browse endpoint `/api/v2/deals/esbrowse/`
accepts a `query` parameter (and ignores `q`), and supports `sort=rating` for
verified highest-rated deals.
