# v0.4.1 — schema-hardening and a 50-product reconciliation

Released 2026-10-07. Not yet tagged.

Hardened the scraper against historical AppSumo schema quirks, proven against a
stratified sample of 50 diverse products.

## Added

- **Sampling and stress tooling** — `scripts/select_50_products.py` and
  `scripts/batch_test_50.py` for automated stratified sampling, stress testing,
  and diagnostic reconciliation.
- **Reconciliation report** — `docs/RECONCILIATION_REPORT_50.md`, certifying a
  100% pass rate across 50 diverse products (3,920 reviews, 9,492 questions,
  422 FAQs, 171 founder updates, and 92.7 MB of structured data).

## Fixed

- **Flexible scalar decoding** — added `FlexBool` and `FlexInt` in
  `internal/appsumo/flex.go` to gracefully handle historical AppSumo schema
  anomalies where boolean fields (`pinned`, `resolved`, `approved`, `edited`,
  `followup`, `purchased`) carry ISO 8601 timestamp strings (for example on older
  products) or string numbers (`"1"`, `"0"`), preventing deserialization halts.
- **Safe vote storage** — updated `internal/store/threads.go` with a
  `flexIntToInt` conversion for safe SQLite storage of upvotes and downvotes.
