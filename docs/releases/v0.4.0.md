# v0.4.0 — full product scraping and a resilient HTTP client

Released 2026-10-07. Not yet tagged.

One command now captures a complete AppSumo product dossier — specs, tiers,
terms, FAQs, founder posts, reviews, and questions — into structured files you
can query offline.

## Added

- **`appsumo scrape <slug-or-url>`** — automatically aggregate, scrape, save, and
  cache a complete AppSumo product package (deal specifications, company
  background, founders, licensing tiers, terms & conditions, FAQs, founder posts,
  public reviews, and public questions) into structured JSON files
  (`deal.json`, `reviews.json`, `questions.json`, `faqs.json`, `founders.json`,
  `full_archive.json`) plus a Markdown dossier (`DOSSIER.md` / `SUMMARY.md`).
- **`CleanProductSlug`** — flexibly extract a product slug from arbitrary full
  URLs (`https://appsumo.com/products/<slug>/`), review paths, or a plain slug
  string.
- **Resilient HTTP transport** — increased TLS handshake timeout (25s) and
  automatic exponential retry on transient network errors in `getHTML` and
  `getJSON`.
- **Global PATH exposure** — symlink at `~/.local/bin/appsumo`.
- **Standalone Python harness** — `scripts/appsumo_scraper.py`.
