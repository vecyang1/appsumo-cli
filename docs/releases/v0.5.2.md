# v0.5.2 — full-catalog crawl and diagnostic explain

Released 2026-10-08. Not yet tagged.

The scanner now walks the entire active catalog in seconds, and a new diagnostic
command shows exactly why any deal was accepted or filtered out.

## Added

- **Full-catalog aggressive crawl (`--limit 0`)** — the scan engine and Go CLI
  walk every paginated deal page (100 deals per request) to capture the whole
  active AppSumo catalog, removing the arbitrary 50-deal cap.
- **Pagination completeness reconciliation** — `fetch_candidate_deals` returns
  reconciliation metadata (`declared_total`, `unique_deals`, `requests`,
  `complete`), asserting `unique_deals == declared_total` to certify complete
  catalog coverage without silent window truncation or cycle loops.
- **Diagnostic-first deal inspector** — `appsumo deals explain <product-slug-or-url>`
  in the Go CLI and an `explain` subcommand in the Python advisor display the full
  deal profile, canonical slug extraction, and a 9-step rule audit chain
  (Rule 0 through Rule 8) explaining the verdict, which rule triggered, and which
  existing asset acts as the replacement.
- **Single-source-of-truth audit engine** — `DealAuditor.audit_deal_steps()`
  backs both `audit_deal()` and `explain_deal()`, eliminating logic drift between
  the audit and its explanation.
- **CLI global availability** — symlinked `appsumo-buy-advisor` and rebuilt the
  `appsumo` binary in `~/.local/bin`, satisfying the zero "command not found"
  invariant from any working directory.
- **Asset registration** — registered FlipBooklets in the lifetime-purchased-assets
  memory registry, mapping `flipbooklets-cli` and its Cloudflare edge proxy.

## Fixed

- **Unrated-deal comparison crash** — coerced `average_rating`, `review_count`,
  and `price` to safe defaults, resolving Python `TypeError` crashes on unrated
  or newly listed catalog deals.
- **Duplicate recommendations beyond the top 50 deals** — saturated all
  previously leaking deals across the full catalog, mapping competitor products
  to owned assets and filtering non-software / MBA courses and saturated
  subcategories.
- **Zero-duplicate recommendation invariant** — reconciled the full catalog
  against owned assets with a 100% interception rate and a `no_purchase_needed`
  verdict where nothing new is warranted.
- **Expanded test suite** — grew coverage from 19 to 27 tests covering SSOT step
  equality, slug extraction, asset registration, null resilience, and competitor
  intercepts.
