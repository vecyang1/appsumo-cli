# v0.5.5 — fast local catalog queries and a resilient deal-fetch pipeline

Released 2026-10-08. Not yet tagged.

The latest release: instant offline catalog queries from SQLite, an automatic
fallback when the local snapshot is empty, and a pre-sync gate that skips
redundant network work.

## Added

- **Fast local catalog query (`appsumo deals list --local`)** — added
  `ListDealsQuery` in `internal/store/deals.go` and a `--local` flag to
  `appsumo deals list`, enabling instantaneous (<0.08s), offline-safe
  full-catalog queries directly from SQLite.
- **Resilient deal-fetch pipeline with auto-fallback** — `fetch_candidate_deals`
  in `appsumo_buy_advisor.py` prefers local SQLite snapshots for catalog audits,
  with seamless automatic fallback to the live remote API when the local cache is
  absent or empty.
- **Expanded unit-test coverage** — added `TestStoreListDealsQuery` in Go and new
  Python cases (`test_fetch_candidate_deals_prefers_local`,
  `test_fetch_candidate_deals_fallback_to_live_on_empty_local`), bringing the
  suite to 33/33 passing.

## Fixed

- **Pre-sync weekly skip gate** — `scripts/run_appsumo_buy_advisor.sh` now checks
  the weekly atomic success marker (`YYYY-WW.success`) *before* running
  `deals sync`. When skipped, execution completes in 0.11s with 0 network calls
  (previously 3.4s with 4 redundant HTTP requests).
- **Owner surface clarification** — updated
  `docs/cadence/CAD-20261007-appsumo-weekly-buy-advisor.md` and the 2nd Brain
  `cadence-commands.md` to cleanly separate `Output Owner` (Notion task page,
  local SQLite deals snapshot, receipts) from `Source Refs`, aligning with the
  scheduled-task-rescheduler standards.
